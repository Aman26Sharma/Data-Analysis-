# FIFA 23 Player Data Analysis (R)

### Project Summary

* Performed exploratory data analysis and predictive modeling on the FIFA 23 Players Dataset.
* Focused on understanding key player attributes and their relationships using R.

### Key Analysis

* Variable exploration using ggpairs to study correlations and trends.
* Classification tree to predict international reputation based on performance metrics.
* Regression modeling to estimate player market value using selected features and PCA.

### Tools & Techiniques

* Languages & Libraries: R, ggplot2, GGally, rpart, caret, MASS
* Methods: Stepwise selection, PCA, Polynomial regression, Tree-based modeling

### Outcomes

* Identified strong relationships between ratings, stats, and value.
* Built interpretable and effective models for both classification and regression tasks.
